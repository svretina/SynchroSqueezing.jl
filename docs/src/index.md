# SynchroSqueezing.jl

This documentation describes the periodic ContinuousWavelets.jl adapter, the
complete first-order WSST pipeline, frequency-constrained ridge tracking, and
conservative ridge-band component reconstruction.
It also supports analytic component envelopes and damping-time estimation.
